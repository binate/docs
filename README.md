# Binate docs

Documentation for the [Binate](https://github.com/binate) programming language
and toolchain.

- [`spec/`](spec/00-index.md) — the core language specification.
- [`abi/`](abi/00-index.md) — the ABI specification (per-target calling
  conventions, symbol naming, linkage, the C boundary).
- [`guide.md`](guide.md) / [`overview.md`](overview.md) — informal docs.

Part of the Binate project workspace, alongside `binate` (self-hosted
toolchain), `explorations` (design notes), `bootstrap`, and `website`.
